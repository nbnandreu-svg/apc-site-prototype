# Прототип сайта Агропромцифры

Настольный интерактивный прототип по предоставленным PDF, изображениям и [макету Figma](https://www.figma.com/design/mk2nkvP1F7PQZm8HglJ1QM/Untitled?node-id=2333-7). Основной размер для просмотра: 1440 пикселей по ширине. Мобильная версия в эту работу не входит.

## Запуск

Требуется Node.js версии 22.13 или новее. В PowerShell из этой папки:

```powershell
npm ci
npm run dev
```

Откройте [локальный прототип](http://127.0.0.1:5173/). Для остановки сервера нажмите Ctrl+C в его терминале. Файл `start.ps1` выполняет установку зависимостей при первом запуске и запускает тот же сервер.

## Поведение

- Инфографика первого экрана слегка движется. Лента партнеров непрерывно повторяется без разрыва.
- Блок аудиторий закрепляется на экране. Прокрутка меняет четыре карточки по очереди, затем освобождает страницу. Обратная прокрутка возвращает карточки. Доступны нажатия и стрелки клавиатуры.
- Семь направлений на карте переключаются через вкладки и сами ячейки карты.
- Радар вращается по циклу в 14 секунд. Красные обводки становятся зелеными при проходе переднего края луча. Перед следующим проходом состояние сбрасывается. За пределами экрана анимация приостанавливается.
- Меню ведет к соответствующим разделам. Новости открываются в диалоговом окне с материалами из макета.
- Системная настройка уменьшения движения отключает постоянные анимации и принудительную прокрутку.

## Границы прототипа

Форма проверяет обязательные поля и показывает демонстрационное сообщение. Отправка заявки и серверная обработка не подключены. Кнопка скачивания чек-листа отключена. Документ политики обработки данных пока не подключен.

Тексты `Lorem ipsum`, `Описание`, `Текст`, `Текст/инфографика/логотипы` и незаполненные показатели сохранены из исходных материалов. Их нужно заменить согласованным содержанием перед публикацией. Полных текстов новостей в материалах нет, поэтому в окне показываются изображение, заголовок и дата.

## Файлы

- `app/page.tsx`: меню, первый экран, лента партнеров.
- `app/Sections.tsx`: остальные блоки, переключения, прокрутка и радар.
- `app/globals.css` и `app/sections.css`: оформление.
- `public/assets`: локальные изображения, SVG и шрифты, используемые страницей.

Все ресурсы страницы хранятся локально. Исходные материалы пользователя и файл Figma не изменялись. Технологии: React, TypeScript, Vinext, Vite и компоненты Base UI. Проверка типов: `npx tsc --noEmit`. Сборка: `npm run build`.
